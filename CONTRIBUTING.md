# CONTRIBUTING

We'd love your help!

## Inner loop

```bash
# Build
cargo build

# Test
cargo test
```

## Submitting code

- Use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/), e.g. `fix(protocol): prevent Toasters from Toast()ing Bread that has Jam`
- Use the pull request template.
